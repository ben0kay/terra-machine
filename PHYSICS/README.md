# Physics helpers

`StaticCollision/` owns reusable opt-in construction of native static colliders for any fixed object: rocks, trunks, furniture or other scenery. It has no vegetation or Voxel Tools dependency. Movement and terrain-specific physics stay with their existing owners.

This is a small shared construction utility, not a simulation/streaming manager or a gameplay inheritance hierarchy. See StaticCollision/README.md for profiles, performance and adoption.
