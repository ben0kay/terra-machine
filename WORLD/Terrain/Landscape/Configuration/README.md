# Landscape configuration

`LandscapeMaster.tres` is the shared test-landscape configuration. Tune plateau dimensions, mountain/detail strengths and the broad mountain approach's centre, radii and height, then restart the scene to rebake. All dimensions are metres. There are no route control points or narrow path-width settings in this pass. The 1024 m domain matches native terrain bounds; changing bounds/resolution requires coordinated integration and shader changes.
