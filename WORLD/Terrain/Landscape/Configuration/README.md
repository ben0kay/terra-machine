# Landscape configuration

`LandscapeMaster.tres` is the test landscape's shared authoring configuration. Change plateau dimensions, mountain/detail strengths and walking-route control points here, then restart the test scene to rebake. Widths are half-widths in metres. Route points use X/Y/Z, with Y the walking elevation. The fixed 1024 m domain matches the current native terrain bounds; changing bounds/resolution requires coordinated integration and shader changes.
