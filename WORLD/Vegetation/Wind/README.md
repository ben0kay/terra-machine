# Shared vegetation wind — awaiting local validation

vegetation_wind.gdshaderinc supplies one world-space breeze/gust function shared by Bermuda, GrassMedium, the legacy meadow material and opt-in plant materials. project.godot registers four global parameters. Edit Project Settings → Shader Globals: vegetation_wind_direction (Vector2), vegetation_wind_strength (world metres, default 0.09), vegetation_wind_speed (default 1.1) and vegetation_wind_gusts (default 0.3). Global registration must exist before shaders compile. Future runtime controls can call RenderingServer.GlobalShaderParameterSet on changes; there is no manager or polling loop in this pass.

Rooted displacement is evaluated in the vertex shader, then converted from world to local space to preserve a common direction despite random plant yaw/scale. Position-based phase varies nearby plants; shared TIME provides coherent gusts. Same near/far placement origins and shader keep GrassMedium's three LOD phases matched. wind_response and wind_plant_height remain per-material tuning. Roots at/below local Y zero stay fixed; this initial height mask is not authored per-frond weighting.

FernsMaster now explicitly assigns Ferns001/Materials/FernWind.tres, using plant_wind.gdshader with the existing colour/alpha, normal and roughness textures. It has a gentler 0.7 response and 0.35 local height. Future compatible plants opt in by assigning a material with this shader and appropriate maps/height/response. No trees, moss or dead branches opt in. The model imports remain untouched. Alpha-scissor rendering is retained.

Strength <=0 returns before wind trigonometry; normal rendering still costs GPU work. No per-plant script/timer/material writes or new CPU frame callbacks exist. Existing placement and streaming lifecycles remain. Fern batches add 0.25 m cull padding; grass tile bounds already include padding. Modest deformation does not regenerate normals, alter collision, or physically bend individual fronds. Static foliage and disabled global intensity retain ordinary rendering cost.

GrassMedium forest settings now use 4.2–5.4 uniform scale (previously 3–4), 2.4 candidates/m² (previously 1.8), and 5.8 m nominal patch radius (previously 5); spacing stays 15 m. Varied diameters are about 8.7–13.9 m, with more overlap and fuller interiors. Terrain reads the same recipe on initialisation so grass ground continues to match the clumps. All three LODs, distance thinning, native culling and shadows-off remain. More density increases render cost; no measured FPS claim.
