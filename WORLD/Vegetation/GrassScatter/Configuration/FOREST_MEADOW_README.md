# Forest GrassMedium clumps — awaiting local validation

ForestMeadowMaster.tres and the existing ForestMeadowScatter node name are retained for stable F1/composition references, but their active assets are now GrassMedium001 rather than GrassMeadow001. The old anchored MeadowPreview instance was removed from test.tscn, so it does not add the old meadow grass around the original trees. Its reusable scene still serves the moss/fern/branch layers. The original Bermuda base remains independently configurable.

The three exported scenes contain 17 matching named variants each. This pass selects nine (large A/B/C, mid A/B/C and tall A/B/C), pairing names by _LOD0/_LOD1/_LOD2 suffix rather than sibling order. Small/tiny variants remain available for later tuning. Blender display translations are ignored. All three levels share the near mesh's ground/base pivot and identical instance transforms to prevent LOD movement; original export geometry and textures are untouched.

Defaults: jittered patch centres 15 m apart; nominal radius 5.8 m, varied 0.75–1.2 (roughly 8.7–13.9 m diameter). 2.4 candidate tufts/m² inside the patch mask before 94–98% acceptance and slope rejection; 4.2–5.4 uniform scale, full yaw and surface-normal alignment. This makes the 14–32 cm native source plants visibly larger while preserving mixed heights. 8 m streaming tiles use native LOD0 below ~14 m, LOD1 from ~14–32 m, and LOD2 beyond ~32 m until final 70 m fade/density cutoff. Distances use native tile AABB centres, not individual plants. One-metre hysteresis, shared bounds, no blend fade. All LOD resources remain resident for active tiles.

ForestGrass.tres supplies a double-sided alpha-scissor diffuse shader, threshold 0.4, with rooted GPU wind adjusted for these short source meshes. No full alpha blending or per-tuft callbacks/colliders. Normal/roughness source maps remain available but this first grass shader uses its shared roughness constant.

Ground.gdshader reproduces the scatter's world-cell hash/jitter/radius formula. TestWorld supplies the forest area plus patch spacing/radius/seed/slope once through ITerrainForestFloor. Grass ground colour, normals and roughness follow the same patches; leaf colour is suppressed under them and remains visible in the open floor. Ground boundaries fade across a metre, while actual tufts use the hard patch boundary and native terrain ray normals. Shader slope uses the existing baked map, so exact per-ray rejection and individual random/slope/loading holes are not painted into the ground. The pattern remains stable when grass is culled or hidden in F1.

Performance: one existing 4 Hz tile timer while visible; capped 32 surface queries per active physics tick; physics sleeps once jobs finish and restarts for travel/loading retries. Hiding pauses both. Shared GPU materials, per-variant/tile/LOD MultiMeshes, shadows off, density thinning to 25% by 48 m. The terrain adds nine cell/hash checks per fragment for the shared patch pattern, with no new texture reads for grassy ground (existing grass PBR samples are reused). No FPS claim without profiling.
