# Meadow grass around preview trees — awaiting local validation

`MeadowPreview.tscn` is an isolated, optional visual trial in `WORLD/Scenes/test.tscn`. It uses the same 16 authored positions from `TreePreview.Settings.Offsets` plus the test spawn XZ; there is no second copy of those offsets. It does not modify the existing Bermuda grass scatter. It samples a few irregular lobes within roughly 5.5 m around each tree and rejects placement inside 1.4 m of the trunk, on slopes above 32°, and where native terrain collision is not ready.

The three new `ASSETS/Vegetation/Grass/GrassMeadow001/Models/*_LOD1.gltf` sources each contain one clump mesh. Imported near-range mesh geometry is approximately 1.0–1.2 m tall; preview scale is 0.8–1.25. Their existing shared `MeadowWind.tres` shader supplies optional GPU-only swaying and masked alpha, with no CPU animation. This is a visual preview, not collision, a global biome system or meadow LOD2 switching. The LOD2 files remain available for a later distance system. No model/texture/shader sources were edited.

Once terrain spawning succeeds, placement samples at most 40 candidates/ground probes per physics tick. Unavailable tree centres are retried by a 0.6 s one-shot timer, with a 12 s overall timeout; no repeated work after success/timeout. The final visual uses at most three shared `MultiMeshInstance3D` batches (one per variant) with shadows disabled and a 140 m batch visibility distance. It stores no per-clump nodes/scripts and no ongoing CPU timer. The wind shader is an intentional active GPU effect when visible. Hiding the root while placing suspends it; re-enabling resumes. There is no streaming or regrounding after terrain edits.

Run `test.tscn` in Godot .NET. The HUD shows Meadow clumps when placed. Press **F1 → OTHER MODELS → Visible: MeadowPreview** to compare on/off; Bermuda grass has its own control. Walk up to the existing trees and inspect height, cutout edges, surface alignment, root sinking, patch continuity, wind and frame time with F2. Wait for collision loading to finish before judging final density. F1's five-case benchmark holds the new meadow's current visibility unchanged, so manually toggle it for its isolated cost. Build/Godot renderer and final appearance are **not verified** here; check them locally.
