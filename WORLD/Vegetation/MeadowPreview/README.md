# Clumped meadow and forest-floor preview — awaiting local validation

MeadowPreview is a finite seeded placement/batching helper. The original MeadowMaster uses the 16 TreePreview offsets, now with three tighter 0.9 m bunches per site instead of broad overlapping lobes. Tune ClumpsPerSite, ClumpRadius, PatchRadius, SamplesPerTree and scale bounds in the inspector/resource.

The test scene also reuses this helper for NatureRoot/Floor/Moss, Ferns and Branches. Their separate Configuration/MossMaster.tres, FernsMaster.tres and BranchesMaster.tres expose site count/spacing, samples, patch/bunch radii, uniform scale range, slope, sink, draw distance and work limits. InitialiseArea distributes separated sites inside an ellipse based on the forest footprint (centre offset ×0.65, radii ×0.7), concentrating this first preview toward the forest entrance. Targets are nine moss patches ×160 tiny sprigs, 22 fern groups ×5 plants, and eight individual dead branches, before slope/missing-ground rejection.

CollectAllMeshes extracts each imported sibling as a separate variant, retaining its basis but ignoring Blender display translations. Moss has 12 variants, ferns four and branches three. Moss native geometry is only roughly 1–2 cm wide; 3.5–4.5 scale gives a visible low carpet, while ferns use 0.9–1.2 and branches 0.9–1.15. All instances have seeded full-circle yaw and uniform size variation. Imported foliage retains its PBR textures, with shared cloned alpha-scissor materials (0.4 threshold) and anisotropic mip filtering. Meadow retains its shared GPU wind shader. These are editable defaults requiring visual review, especially tiny moss coverage.

Each floor layer uses a bounded 16-query physics budget and 20-second loading window. Placement starts after successful player spawn, retries unavailable site centres using a one-shot timer, and stops all physics/timers after completion or timeout. F1 visibility pauses unfinished work. Finished visuals use per-variant MultiMeshes grouped into 16 m spatial cells for native culling; no per-plant scripts, animation, distance checks or physics are added for moss/ferns. Draw distances are 55/90/110 m. F1 OTHER MODELS exposes each floor layer independently. This finite preview remains resident; it does not stream or reground after terrain edits.

Branches explicitly use the shared PHYSICS/StaticCollision system through BranchCollision.tres. One simplified convex hull is prepared per variant, then shared by its placed static bodies, with layer 4/mask 0. Bottom grounding, slope alignment, scale and yaw match the visible mesh. Small gaps/forks may be filled by the convex proxy; it is not an exact triangle collider. Visual culling/F1 hiding preserves collision. Mode None disables collision on restart.

ForestPreview already varies tree scale and seeded 360° yaw; the original 16 trees also have varied scale and golden-angle yaw. Trees stay upright rather than inheriting terrain tilt. Active Pine002 now points to the renamed latest PineTree002 assets.

Source references, JSON/buffer links and edited loops were reviewed. **Compilation, Godot import, appearance, contact fit and FPS are unverified here.** Locally build/run test.tscn, inspect floor patches at eye level, toggle each layer in F1, check F2 frame time, and use Visible Collision Shapes to check branch contact at several scales/yaws. F4 should not duplicate placements. Check that fern/moss cutouts remain clean and that ground follows the slope without floating. Restart after changing resource composition settings.
